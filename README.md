# UQ Program Development Analysis Work Sample

Independent recruitment work sample prepared by Yaxiya (Cynthia) Li for the Senior Program Development Analyst role in UQ Planning & Business Intelligence (R-69143).

The work sample shows how I would approach an illustrative program-development question by:

- framing the decision before modelling;
- separating public evidence from internal data requirements and synthetic assumptions;
- reviewing internal and external comparators;
- specifying the data pull and reconciliation checks;
- testing demand, commencements, EFTSL/load, pricing and viability; and
- synthesising the evidence into a concise recommendation and analysis workplan.

The illustrative program concept is not a UQ proposal. No UQ internal application, load, pricing, cost, market-research or business-case data is used. Synthetic values are labelled as such.

My transferable experience includes enterprise financial and portfolio analysis at Rio Tinto, scenario modelling, data reconciliation, executive decision support, research/survey analysis and cross-functional stakeholder facilitation.
