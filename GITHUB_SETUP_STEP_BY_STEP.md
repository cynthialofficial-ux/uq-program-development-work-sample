# GitHub Pages setup / update

Repository name: `uq-program-development-work-sample`

Expected live URL:
`https://cynthialofficial-ux.github.io/uq-program-development-work-sample/`

## If the repository already exists

1. Open the existing repository in GitHub.
2. Select **Add file -> Upload files**.
3. Upload these four files to the repository root:
   - `index.html`
   - `styles.css`
   - `UQ_Program_Development_Analysis_Work_Sample.xlsx`
   - `README.md`
4. If GitHub warns that files with the same names already exist, continue: these are replacements for the old version.
5. Commit directly to `main` with this message:
   `Refine UQ program development analysis work sample`
6. Do **not** create a new repository. Keeping the existing repository preserves the URL already used in the CV.
7. Wait 1-3 minutes for GitHub Pages to republish.
8. Open the live URL. If the old version appears, use Ctrl+F5 or open an incognito window.

## If GitHub Pages is not enabled yet

1. Repository -> **Settings** -> **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Branch: `main`.
4. Folder: `/ (root)`.
5. Save.
